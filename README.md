# 成长星球 · 科学班生态（Primary-school-teaching-aids）

小学科学课堂辅助工具：每个孩子认领一个"生命伙伴"，全班伙伴组成一颗"生态星球"。
老师课堂上即时点评，伙伴当场产生生态反馈（开花/发光/长叶/藤蔓/进化），提升学习积极性与科学兴趣。

## 目录结构

```
design/   产品设计文档（需求调研、访谈提纲、最终报告、伙伴自选设计、年级偏好调研、设计说明）
frontend/ 前端（老师大屏驾驶舱高保真原型 HTML + 伙伴自选演示 HTML，自包含可直接浏览器打开）
deploy/   后端架构与部署方案 + docker-compose + 初始化SQL + Nginx配置 + .env样例（老师账号/多设备同步）
```

## 当前进展

- ✅ 伙伴自选设计（1–6 年级分层，原创无版权风险）
