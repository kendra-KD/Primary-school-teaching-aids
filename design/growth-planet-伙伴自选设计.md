# 成长星球·科学班生态 —— 伙伴自选设计方案（年级分层）

> 解决：每个同学自主选择自己的宠物/植物/感兴趣的东西；1–6 年级审美不同，伙伴库需分层；
> 暂不开发学生端，但设计要预埋，后续学生端扫码认领即同步回老师大屏。
> 版权红线：绝不内置受保护 IP（皮卡丘/奥特曼/原神等），用原创元素精灵替代 + 自定义昵称满足情怀。

---

## 一、核心机制

```
老师建班时选年级 → 锁定「主题包」
        │
        ▼
老师大屏「⚙ 伙伴库」生成入班码（班级UUID短码）
        │
        ▼（学生端上线后）
学生扫码进本班 → 浏览「生命库」（按主题包过滤 20–30 种）
        │
        ▼
选 1 个认领 → POST /api/students/:id/claim → 老师大屏该同学伙伴即时变更
        │
        ▼
后续答题/作业/观察 → 伙伴进化（蛋→幼体→成体→进化）
```

MVP（暂不开发学生端）降级方案：老师在「⚙ 伙伴库」里**代学生预选**（下拉选种类），学生端上线后学生可自行改。

---

## 二、分年级主题包（关键设计）

| 包名 | 适用年级 | 视觉 | 示例伙伴（原创，非IP） |
|---|---|---|---|
| 萌系自然包 | 1–2 | 圆润拟人、糖果色 | 团团熊、芽芽、云朵羊、星仔 |
| 生命观察包 | 3–4 | 真实小生命+科幻萌宠 | 蚕宝、蝌蚪、晶簇、种子精、蚁工 |
| 动漫原创包 | 5–6 | 原创动漫风、元素系 | 火灵/水灵/草灵/电灵（原创）、星灵、机械生态 |

每班建班选年级 → 默认主题包，老师可手动改。伙伴库按包过滤展示。

---

## 三、伙伴数据结构（前端/后端通用）

```js
{
  kind: "can_bao",          // 唯一 key
  name: "蚕宝",             // 默认名（学生可改昵称）
  pack: "life_obs",         // 主题包
  stage: 0,                 // 0蛋 1幼体 2成体 3进化
  rarity: "common",         // common/rare/epic（高年级稀缺感）
  color: "#A8E6CF",         // 主色（可自定义）
  shape: "svg_cocoon"       // 前端绘制形状 key（CSS/SVG，非图片，省流量）
}
```

进化触发（与科学点评联动）：
- 提出好问题/观察记录 → stage 进度+
- 长期观察打卡（养蚕/种豆）→ 解锁 rare 装扮
- 答错/不交 → 仅不增长，不退化不羞辱（守红线）

## 四、入班码认领流程（学生端预埋）

1. 老师大屏点「⚙ 伙伴库」→「生成入班码」→ 显示二维码（含 `https://域名/join?c=班级短码`）。
2. 学生机扫码 → 打开学生端轻网页 → 自动带入班级 → 显示本班「生命库」。
3. 学生点选伙伴 → 确认认领 → 后端写 `partner_claims` + 更新 `students.partner_kind`。
4. 老师大屏 `GET /api/classes/:id/state` 拉取最新 → 该同学伙伴形象实时变。
5. 未认领学生：老师可代选（降级方案），或显示"待认领"占位。

---

## 五、版权与避坑

- **绝不内置受保护 IP**。热门动漫角色用"元素精灵/星灵"等原创抽象形象替代。
- 提供「自定义昵称 + 主色」让高年级有掌控感，满足情怀而不侵权。
- 伙伴用 SVG/CSS 形状绘制，不依赖图片资源，减小体积、规避图库版权。
- 若学校要求特定 IP 形象，走"学校获授权后自定义上传"通道，不在默认库内置。

---

## 六、老师大屏原型如何加入口（MVP 可先做静态版）

在顶部栏「⚙ 花名册」旁增加「⚙ 伙伴库」按钮：
- 打开模态：显示本班主题包、伙伴列表（可下拉改每个学生的伙伴种类）、「生成入班码」占位按钮（学生端上线后生效）。
- 改动写回 localStorage（MVP）/ 远程 API（部署后）。
- 详见演示 HTML：`growth-planet-伙伴自选演示.html`。

## 七、后续学生端（预埋，不阻塞）

- 独立轻网页 `/join?c=短码`，技术同老师端（自包含 HTML + fetch API）。
- 认领/作业接口已在后端 `partner_claims` / `submissions` 表与 API 预留。
- 学生端上线不改动库结构，只补前端 + 接口实现。
