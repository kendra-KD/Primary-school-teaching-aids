> 调研角色：需求调研员「许清楚」｜ 输入文档：`小学课堂成长伙伴工具_设计方案.md`(v1.0)

> 目标：把通用版方案压实到具体真实场景，作为 Phase 1 老师大屏高保真原型的直接输入。

## 0. 执行摘要（给主理人 / UI 设计的一页结论）

| 维度 | 关键结论 |
|---|---|
| 用户差异 | 不是"通用小学老师"，而是**科学老师 + 跨班任课**：课堂以实验/观察/探究为主，器材与生命材料管理重，备课负担本就大，对工具"零额外备课"要求极高。 |
| 核心痛点 | 多班级带来三大硬需求：**上课前 30 秒一键切班、班级数据严格隔离、跨班进度/活动周期不同**。通用工具把这三点当"顺便支持"，本产品必须当"一等公民"。 |
| 最大差异化 | 行为标签**只服务于科学学科**——提出好问题、规范实验、观察记录、爱护实验生物/植物、整理器材、工程小制作等，是区别于希沃/Dojo 通用纪律积分的护城河。 |
| MVP 边界 | 首版**只做老师大屏 Web 驾驶舱**：切班 + 隔离 + 生态墙 + 科学点评面板 + 光荣榜 + 成长卡浮层 + 进度环 + 音效动效；学生端/家校/公益/自定义标签全部后置。 |
| 形态与名 | 沿用"成长星球"主品牌，副标题点明科学；首版技术形态**推荐 Web 大屏网页**（零安装、低成本、弱网可本地缓存），家校/学生端后续用小程序补。 |

## 1. 用户画像：多班级小学科学老师

### 1.1 科学学科特征（决定工具"该长什么样"）

依据《义务教育科学课程标准（2022 年版）》，科学课的核心素养为 **科学观念 / 科学思维 / 探究实践 / 责任态度**，教学以**探究和实践**为主，不是听讲刷题。这直接决定了本工具的行为激励应围绕"做科学"而非"守纪律"。

**科学课典型活动形态（工具的日常触发场景）**

| 活动类型 | 课堂真实画面 | 对工具设计的启示 |
|---|---|---|
| 动手实验 | 电路连接、水的三态、种子发芽、磁铁、杠杆 | 操作规范 + 安全是高频点评点；课堂"乱"但热闹，点评要**极快、零打字** |
| 观察记录 | 养蚕/种豆日记、天气记录、月相、校园动植物 | 强调**长期连续观察**，适合"成长+进化"长线激励 |
| 提出猜想/好问题 | 先猜"为什么会沉浮"再验证 | "敢提问"是科学思维起点，应被单独表扬 |
| 小组探究 | 4 人一组分工做实验、写报告 | 天然适配"连接藤蔓 / 共生榜" |
| 生命科学养护 | 养蚕、种凤仙花、养蜗牛/小鱼 | **爱护生命**是科学学科独有价值观，需专属正向反馈 |
| 技术与工程 | 建纸桥、做小船、风力车 | "创新小制作"值得"进化"级奖励 |
| 器材整理 | 实验后归位烧杯、收种子 | 实验室责任，可映射为"星球整洁度" |
| 科学阅读/资料 | 查资料、自然笔记、科普书打卡 | 持续学习行为，适合打卡成长 |

### 1.2 "任教多个班级"的核心管理痛点（决定工具"能不能用"）

科学老师常跨年级、跨班级排课（一天 4–6 节，班级轮换）。通用班级工具多以"单一班主任管一个班"为默模，多班级是它的软肋。

| 痛点 | 真实场景 | 对工具的具体要求 |
|---|---|---|
| **① 极速切班** | 下节课换班，课前 30 秒要切到正确星球，不能翻菜单 | 登录后班级以**卡片/标签墙**呈现，一键进入；记住"上次班级" |
| **② 数据严格隔离** | A 班养蚕进度、B 班种豆进度完全不同，切换后状态必须即时且准确，不能串班 | 每班**独立数据库/命名空间**，切换即加载该班专属生态，零串扰 |
| **③ 跨班进度差异** | 三年级养蚕（3–4 月）、五年级做桥梁（随时）；不同班生命科学活动周期不同 | 班级级"活动/主题"可独立设置，不强制统一；MVP 可先给**预置学科主题**而非自定义 |
| **④ 备课负担** | 科学课本就要备器材、备活体材料，工具不能再加备课 | 点评标签**预置好**（科学专属），老师不配规则；操作零输入 |
| **⑤ 课堂即时性** | 实验课混乱度高，老师手忙脚乱 | 点评 = 点伙伴 + 点标签，两步完成；支持**随机点名/小组**批量 |
| **⑥ 设备环境** | 科学教室/普通教室大屏，网络可能不稳 | Web 方案需**本地缓存 + 弱网容错**，断网也能评，联网再同步 |
| **⑦ 横向对比（弱需求）** | 年级组偶尔想看各班表现 | MVP **不做**，后置"年级视图" |

## 2. 科学学科专属课堂正向行为清单（差异化核心）

> 设计原则：每条都**带科学学科语境**，反馈复用原方案的 活力+ / 成长+ / 藤蔓 / 开花 / 进化 / 蔫了（可恢复）机制。
> 评分用轻量 +1~+3，避免复杂配置（呼应"零备课"）。

| # | 行为标签（科学语境） | 学科含义 | 生态反馈（沿用机制） | 建议分值 | 设计意图 |
|---|---|---|---|---|---|
| 1 | **提出好问题 / 大胆猜想** | 科学思维起点 | 伙伴头顶冒"?"气泡 → 开花 | +2 | 鼓励敢想敢问，区别于"举手发言"通用项 |
| 2 | **规范操作实验** | 实验室安全与规范 | 活力+：伙伴发光、蹦跳 | +2 | 安全是科学课红线，即时正反馈 |
| 3 | **认真观察并记录** | 观察记录能力 | 成长+：伙伴长新叶 | +2 | 对应观察日记长线行为 |
| 4 | **爱护实验生物/植物** | 生命科学态度（独有） | 伙伴被温柔对待 → 回以"拥抱"动画，生命值+ | +3 | **学科独有价值观**，也是情感羁绊最强点 |
| 5 | **小组合作探究** | 探究实践 | 伙伴间长出**连接藤蔓** | +2 | 复用共生机制，可视化合作 |
| 6 | **主动整理/归位器材** | 实验室责任 | 活力+ + 星球"整洁度"上升 | +2 | 把实验室规矩变成集体收益 |
| 7 | **完整表达探究结论** | 科学表达 | 成长+：伙伴进化一级 | +3 | 奖励"做完了还能讲清楚" |
| 8 | **科学阅读 / 资料打卡** | 持续学习 | 成长+：伙伴长"知识叶" | +1 | 低成本日常打卡，天天可触发 |
| 9 | **创新小制作 / 工程挑战** | 技术与工程 | 进化：解锁新形态 | +3 | 对应建桥/造船等工程活动 |
| 10 | **帮助同学 / 分享发现** | 互助 | 连接藤蔓 | +2 | 通用正向行为，科学课同样高频 |
| 11 | **坚持长期观察**（如养蚕日记连 N 天） | 长期责任 | 进化 + 稀有装扮 | +3（达成时） | 把"连续观察"变成可炫耀成就 |
| 12 | **安全提醒 / 保护同伴** | 安全意识 | 活力+ | +2 | 实验课同伴安全互相监督 |

**科学学科专属负向（可恢复，不羞辱）**

| 行为 | 生态反馈 | 说明 |
|---|---|---|
| 不安全操作（拿器材打闹） | 伙伴「蔫了」：低头垂叶 | 可恢复，明日养回 |
| 破坏/怠慢实验生物植物 | 伙伴「受伤」：需老师/同学"照料"动作恢复 | **生命科学专属**：强调"生命需要被负责"，但仍可恢复、不公开批评 |
| 不及时整理器材 | 星球「整洁度」下降 | 集体可恢复，不点名个人 |

> ⚠️ 差异化要点：通用积分系统只有"纪律/作业/助人"，而本清单里 **①提出好问题、③观察记录、④爱护生命、⑥整理器材、⑨工程制作、⑪长期观察** 是**只有科学课才有的行为**——这正是本产品不能被希沃/Dojo 直接替代的理由。

## 3. 竞品差异化借鉴（科学学科 + 多班级视角重评）

| 工具 | 原借鉴点 | 在"科学+多班级"下的**局限** | 本产品**应强化的差异点** |
|---|---|---|---|
| 希沃班级优化大师 | 点选零成本、光荣榜、装扮、家校同步、且**原生支持多班级切换** | 行为是通用的（纪律/作业），**无科学学科标签**；可视化是单个卡通头像，**无生态/生命伙伴情感**；多班下光荣榜仍是通用纪律 | 吸收其"多班级切换+装扮收集"，但把头像升级为**生态星球+生命伙伴**，标签换成科学专属 |
| ClassDojo | 零学习成本、"叮"音效、即时反馈、家长门户、标签可自定义 | 标签通用、无学科语境；多班需手动建；反馈只是头像发光，**无成长可视化** | 保留"叮"音效与零成本，但把反馈升级为**生态变化（开花/藤蔓/进化）** |
| Classcraft | 小组共生、集体责任、RPG 叙事 | **配置成本极高**（与"备课负担重"直接冲突）；适合高年级 RPG，低龄科学课水土不服；多班配置是灾难 | **只取"小组共生+集体责任"轻量版**，砍掉 RPG 配置地狱 |
| Forest | 成长可视化、情感羁绊、公益种真树 | 单人专注、无多学生/多班集体、无行为映射（仅计时） | 放大"**全班共养一个星球**"；其"公益种真树"与"生命科学/爱护植物"主题**天然契合**，后置阶段优先做 |

**本产品应强化的 5 个差异点（优先级排序）**
1. 🥇 **科学学科专属行为体系**（提出好问题/观察/爱护生命/工程）——护城河，通用工具没有。
2. 🥈 **生命伙伴情感羁绊**（"值得负责的生命"而非积分）——承接 Forest 羁绊 + 科学"爱护生命"价值观。
3. 🥉 **多班级一等公民**（一键切班 + 严格隔离 + 班级独立主题）——直击科学老师跨班痛点。
4. **生态可视化（非头像）**——全班共养星球，远距可读，集体荣誉强于个人头像。
5. **去羞辱化 + 生命科学"可恢复受伤"**——比通用扣分更贴合低龄与生命教育。

## 4. MVP 范围建议（首版只做老师大屏驾驶舱 · 低成本 Web）

### 4.1 必须包含（MVP 做）

| 模块 | 说明 | 多班级/科学相关要点 |
|---|---|---|
| 老师登录 + 班级列表 | 卡片式班级墙，一键进班，记住上次班级 | 多班级切换零摩擦 |
| **班级数据隔离** | 每班独立命名空间，切换即加载该班生态 | 跨班不串数据（痛点②③） |
| 生态星球主视觉 | 全班伙伴墙全景，远距可读（亮=活跃/垂=蔫） | 科学课大屏投影 |
| 一键点评面板 | 预置**科学专属标签**（第 2 节 12 条），点伙伴→点标签 | 零备课（痛点④） |
| 光荣榜 / 共生榜 | 只表扬成长与共生，不公开负值 | 去羞辱化 |
| 个体成长卡浮层 | 进化时间轴 + 预置装扮 + 关系网 | 收集驱动 |
| 集体目标进度环 | 荒芜→绿意→繁荣，全班推进 | 集体荣誉 |
| 音效 + 动效 | "叮"+开花/藤蔓/蹦跳 | 即时多感官反馈 |
| 弱网容错 | 本地缓存点评，联网再同步 | 科学教室网络不稳（痛点⑥） |

### 4.2 可后置（P2 及以后，MVP 不做）

| 模块 | 后置理由 |
|---|---|
| 学生端养成界面（平板/手机） | 首版老师大屏优先，控制成本 |
| 家校同步 / 家长门户 | 依赖账号体系，成本高 |
| 公益种真树 | 需外部合作，后置（Forest 借鉴点） |
| 标签自定义配置 | MVP 给**预置科学标签**即可，老师不配规则 |
| 数据看板 / 周报导出 | 非即时课堂需求 |
| 年级横向对比视图 | 弱需求（痛点⑦），后置 |
| 装扮商城 / 52 款收集 | 先给预置装扮，商城后置 |

### 4.3 开发成本控制建议
- **形态**：Web 大屏网页（见第 5 节），免安装、免上架、易迭代。
- **存储**：MVP 用轻量方案（本地 IndexedDB + 可选轻云服务），先不建复杂后端。
- **动效**：复用开源/CSS 动效（开花、藤蔓、蹦跳），不自研引擎。
- **标签**：12 条科学标签写死预置，不开放配置后台，省一个管理端。

## 5. 产品名与形态建议

### 5.1 产品名

**建议：沿用主品牌"成长星球"，副标题点明"科学 + 班级"。**

| 选项 | 名称 | 评价 |
|---|---|---|
| 沿用（推荐） | **成长星球 · 班级生态** | 已有认知，副标题已含"班级"；可微调为"成长星球·科学班生态"更贴学科 |
| 备选 A | **奇趣小生态 / 自然伙伴星** | 更童趣、更贴生命科学，但弱化了"成长/责任"主张 |
| 备选 B | **探秘星球** | 强调"探究"，契合科学课；但偏学生向，老师端识别弱 |
| 备选 C | **班级生命树** | 强生命/植物隐喻，公益种树好接；但"树"单一，弱于"星球生态"的多样性 |

> 推荐：主名 **成长星球**，对外可称"成长星球·科学班生态"，既延续文档资产，又用副标题锁定学科。

### 5.2 技术形态

| 形态 | 利 | 弊 | 结论 |
|---|---|---|---|
| **Web 大屏网页** ✅推荐 | 零安装、大屏浏览器直接开；**低成本**契合启动资金极低；易迭代；可本地缓存做**弱网容错** | 推送弱；离线能力需自做；依赖浏览器 | **首版老师端首选** |
| 微信小程序 | 老师/家长易触达；家校同步天然；扫码即用 | 大屏投影体验一般；生态动画性能受限；需审核上架 | **后置做家校/学生端** |
| 独立 App | 体验完全可控；可离线 | 开发/维护成本最高；装机门槛；与学生端耦合 | **不推荐首版**（资金与时间不允许） |

> **推荐路径**：首版 = Web 大屏网页（老师驾驶舱）；Phase 2–3 用微信小程序承接学生端养成与家校同步。既守住"老师大屏优先"，又把低成本贯彻到底。

## 6. 给 Phase 1 高保真原型的输入清单（收尾）

1. **顶部栏**必须含：班级切换入口（卡片墙/下拉）+ 星球阶段 + 今日生态值 + 计时器。
2. **主视觉**是全班生态星球全景，伙伴用大色块简形，状态靠形状/颜色（亮=活跃，垂=蔫），远距可读。
3. **底部点评面板**预置 12 条科学标签（分组：思维/实验/观察/生命/合作/工程/责任），点伙伴→点标签两步完成。
4. **右侧榜**只用"最繁荣小组/最佳搭档/最爱提问"，不出现负值。
5. **浮层成长卡**展示进化轴 + 预置装扮 + 关系藤蔓网。
6. **集体进度环**荒芜→绿意→繁荣，全班共推。
7. **负向反馈**统一"蔫了/受伤→可恢复"，生命类用"照料"动作恢复，绝不公开羞辱。
8. **弱网**：断网可点评，本地缓存，联网同步（科学教室刚需）。
