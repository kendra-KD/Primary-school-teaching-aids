# 用户画像与课堂场景

## 1. 主用户：小学科学老师

### 1.1 画像卡片

| 维度 | 描述 |
|---|---|
| 代表 | 李钰琳老师（四川，小学科学，试点用户） |
| 年龄 / 教龄 | 中青年，有带班经验 |
| 技术能力 | 会用微信、会做 PPT、能看网页；**不接受学习新系统**、不接受装客户端 |
| 设备环境 | 教室电脑（Chrome/Edge）+ 投影大屏；办公室电脑；手机 |
| 课堂形态 | 每周多班多节，每节 40 分钟；以小组探究活动为主 |
| 核心动机 | 想让课堂纪律与参与度更好；想让正向行为「被看见」；不想增加工作量 |
| 主要顾虑 | ① 操作复杂会打断教学 ② 学生排名造成家长意见 ③ 数据安全与隐私 |
| 成功标准 | 「下节课我还想打开它」 |

### 1.2 老师的典型一天（课堂片段）

```
08:40  进教室，打开电脑浏览器（收藏夹里的 gp.mealpick.me），F11 全屏
08:42  星球自动加载完（< 3s），全班 42 个伙伴已经在墙上，状态是上次课的样子
08:50  小组实验开始，巡视中：
        ・小A 规范使用了酒精灯 → 点小A的伙伴 → 点「规范操作实验」→ 伙伴发光 ✔
        ・小B 提问「为什么水会沸腾」→ 点小B → 点「提出好问题」→ 伙伴开花 ✔
        ・小C 和小D 合作搭装置 → 分别点两人 → 点「小组合作探究」→ 两人之间长出藤蔓 ✔
09:20  发现小E 的器材没归位 → 点小E → 点「器材未归位」→ 伙伴蔫了一下（不点名批评）
09:25  小E 主动归位了 → 点「主动整理 / 归位器材」→ 伙伴立刻被养回来 ✔
09:30  下课，星球生态值 +18，进度环离「绿意」又近了一点，全班看到
 
【下课】
10:05  小A 在平板上打开学生端，给自己的伙伴签到、答一道科学题 → 伙伴长大
10:07  李老师讲台上大屏 15 秒内自动跳出小A 的成长变化 → 「小A 课后也很努力」 ✔
```

### 1.3 老师的原话（需求来源，见 [`需求来源原始记录`](../08-项目历程/需求来源原始记录.md)）

> 「在新建班级界面就不要在年级后面写上图鉴风格了，直接写年级就行」
> 「这个 teacher-dashboard.html 主界面设计不太美观，这下面的加分项应该优化一下，这样都挡住了该页面右边部分的内容了」
> 「同学们在上课或者下课期间应该可以和他们自己的伙伴进行互动（方式包括但不限于答题，做作业等内容）」
> 「不要限制每个年级只能选择某一个类型的图鉴伙伴」

## 2. 次用户：小学生（1–6 年级）

### 2.1 画像卡片

| 维度 | 描述 |
|---|---|
| 年龄 | 6–12 岁 |
| 设备 | 家里的平板/手机/电脑（浏览器），校内机房 |
| 心理动机 | **收集**（我想要史诗级）、**养成**（我的伙伴要长大）、**展示**（我的伙伴最特别） |
| 注意力 | 3–8 分钟；对动画、即时的正反馈极敏感 |
| 阻碍 | 不会打字、记不住密码、迷路（不知道点哪里） |
| 设计对策 | 免登录（凭码 + 选名字）、大按钮、图形化图鉴、认领后直接进主页、localStorage 记住身份 |

### 2.2 学生的使用路径

```
老师给一个链接/班级码（或老师直接投屏二维码）
  → 打开页面（自动带码 D9E1B6）
  → 从名单里点自己的名字（40 人名单，靠搜索/滚动）
  → 浏览图鉴（可切换：全部 / 萌系自然 / 生命观察 / 动漫原创）
  → 点一张卡片 → 认领
  → 进入「我的伙伴」主页：动画伙伴 + 生态值进度 + 互动区
  → 🌞 每日签到 / 📚 课间答题 / 🔍 观察记录
  → 伙伴跳动一下，生态值 +N
```

## 3. 场景优先级（MoSCoW）

| 优先级 | 场景 | 理由 |
|---|---|---|
| **Must** | S1 课堂即时点评、S2 大屏氛围、S4 负向不羞辱、S8 换设备可用 | 老师上课的刚需，缺一个产品就不成立 |
| **Should** | S3 合作可视化、S5 学生自主认领、S6 课后延续 | 产品的差异化与学生动机来源 |
| **Could** | S7 大屏实时刷新（已做）、课后知识问答（内容待补） | 体验增强 |
| **Won't（当前）** | 家长端、作业批改、成绩管理、多校协作 | 超出「课堂即时反馈」定位 |

## 4. 关键设计约束（来自用户画像）

| 约束 | 具体化 |
|---|---|
| 零学习成本 | 核心操作 ≤ 2 步；界面文案用小学老师的语言（「爱护实验生物」而非「亲社会行为」） |
| 零安装 | 单文件 HTML，双击即用；不依赖 CDN |
| 大屏可读 | 关键信息（昵称、成长值、状态）在 3 米外可辨识 |
| 弱网可用 | 云端不可达自动降级本地，课堂不中断 |
| 不羞辱 | 负向行为不出榜、不排名靠后、可恢复 |
| 学生零门槛 | 免登录；只需「输码 → 点名字 → 点卡片」 |
