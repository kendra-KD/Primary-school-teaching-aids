# 伙伴互动与生动化设计（汤姆猫式）

> 本文对应需求 **R43（伙伴点击互动 / 生动化）** 与 **R44（工具「师生/工具」互动性整体设计）**。
> 用户原话：
> - 「每个伙伴点开应该可以互动，设计得生动一点，参考汤姆猫——点击不同部位有对应互动」
> - 「之前提出的老师/同学与工具互动性设计文档还没看到」
>
> 设计定位：**R43 是功能设计（待实现），R44 是已落地 + 规划中互动的总蓝图**。功能实现排期见 Phase 4。

## 1. 伙伴点击互动（汤姆猫式部位反馈）— R43

### 1.1 设计目标

| 目标 | 指标 | 手段 |
|---|---|---|
| 伙伴要「活」 | 点开即有回应，不出现「点了没反应」 | 任何有效点击都触发一种反馈 |
| 部位有区分 | 不同部位 → 不同反馈 | 子区域命中检测 |
| 生动不烦人 | 音效克制、可关 | WebAudio 合成短音 + 🔇 开关 |
| 驱动回访 | 互动累积解锁表情/装饰 | 本地计数 + 成长值联动 |

### 1.2 部位映射表（核心设计）

| 部位（data-part） | 触发动作 | 动画反馈 | 音效（合成） | 文案彩蛋（随机池） |
|---|---|---|---|---|
| `head` 头/脸 | 点头 | 上下点头 + 微笑表情切换 | 轻快「你好」滑音 | 「你好！我是你的科学伙伴」「今天也一起探索吧～」 |
| `eye` 眼睛 | 点眼睛 | 眨眼加速 + 眼睛变星星 | 「叮」 | 「我在认真观察世界」「发现了一只小蚂蚁！」 |
| `belly` 肚子 | 点肚子 | 缩放 + 冒小气泡（进食/打嗝） | 「咕噜」 | 「吃饱了才有力气做实验」「 scientist 也要吃饭呀」 |
| `limb` 手/鳍/翅膀 | 点四肢 | 摆动/扇动 | 轻快节奏 | 「看我转个圈！」「我的翅膀准备好啦」 |
| `foot` 脚 | 点脚 | 蹦跳 `hop` | 「boing」 | 「我也会跳远哦」「来场比赛吧！」 |
| `body` 身体（整体/长按） | 长按或双击 | 转圈 + 进化预览 | 升级音 | 「再陪我长大一点吧」「下一阶段是什么样呢？」 |

> 降级策略：若某形象 SVG 未细分部位，则整卡点击统一触发 `body` 反馈，保证「必有回应」。

### 1.3 反馈分层

| 层 | 内容 | 成本 |
|---|---|---|
| L1 微反馈 | CSS transform（点头/眨眼/缩放/hop） | 零成本，纯样式 |
| L2 音效 | `AudioContext` 合成短音（不依赖外部资源） | 低，需用户手势后解锁 |
| L3 彩蛋文案 | 从文案池随机取，定时刷新 | 低，数据驱动 |
| L4 状态联动 | 互动次数累积 → 解锁表情/装饰，驱动回访 | 中，需计数存储 |

### 1.4 实现路径（Phase 4，前端为主）

1. `creature()` 各形象增加可点击子区域（`<g data-part="head">` 等），保留整卡降级点击。
2. 新增 `partnerInteract(part, svgEl)`：查映射表 → 播放对应 keyframes → 播放合成音效 → 概率弹彩蛋文案。
3. 音效用 `new AudioContext()` 合成短 beep / 滑音；提供 🔇 开关，**默认开但首屏静音，待用户首次手势后解锁**（浏览器自动播放策略）。
4. 互动计数：学生端入 `localStorage`，老师端只读（随成长值展示），用于解锁判定。
5. 无障碍：点击区域加 `aria-label`，支持键盘聚焦触发；尊重 `prefers-reduced-motion`（关闭大幅动画）。

### 1.5 验收

- 头/眼/肚/肢/脚各触发**不同**动画；连点不串帧；
- 🔇 开关生效，首次手势前不自动响；
- 移动端触控可用；键盘可聚焦触发；
- 整卡降级点击仍有反馈。

## 2. 工具互动性整体设计 — R44

把**已落地**与**规划中**的互动串成一张「人—工具—伙伴」地图，避免互动能力碎片化。

### 2.1 互动主体

- 老师 ↔ 工具（两步点评链路）
- 学生 ↔ 伙伴（自主互动闭环）
- 学生 ↔ 学生（藤蔓网、合作点评）
- 老师 ↔ 学生（实时大屏、互动明细）
- 伙伴 ↔ 伙伴（藤蔓可视化）

### 2.2 已落地互动（✅）

| 互动 | 触发 | 反馈 | 需求 |
|---|---|---|---|
| 两步点评 | 点伙伴 → 点标签 | 即时特效 + 伙伴 `hop` + 生态值变化 | R01–R07 |
| 撤销 / 照料 | 撤销事件 / 照料 | 成长值回滚 / 状态恢复 | R06, R07 |
| 关系藤蔓 | 合作点评并指定对象 | 连线 + 「最佳搭档」卡片 | R05（用法见 [`课堂点评与学生互动闭环设计.md §3.2`](课堂点评与学生互动闭环设计.md)） |
| 学生签到 / 答题 / 观察 / 作业 | 学生端按钮 | 生态值 + `hop` + 老师大屏 15s 同步 | R19, R32, R34 |
| 实时轮询 | 15s 一次 | 伙伴 `hop` 让「有人在互动」被看见 | R04 |

### 2.3 规划中互动（🟡 / 🔴）

| 互动 | 状态 | 需求 |
|---|---|---|
| 伙伴点击部位反馈（本文 §1） | 设计已出，待实现 | R43 |
| 真实知识点题库问答 | 待教研输入 | R33 |
| 标签挂钩当堂知识点 | 待实现 | R30 |
| 周报 / 成长报告导出（给家长） | 远期 | R38 |

### 2.4 互动设计原则（统一约定）

1. **反馈要「当场」**：点击后 < 300ms 出动画（前端乐观渲染）。
2. **正向为主，负向可恢复**：负向行为不进榜、可照料养回（R07）。
3. **任何互动都可被「看见」**：学生动作 15s 内反映到老师大屏（R04/R34）。
4. **点击必有回应**：哪怕是「我还在想」，避免「点了没反应」的挫败感。
5. **音效克制、可关**：默认轻量、提供 🔇，尊重自动播放与无障碍策略。
