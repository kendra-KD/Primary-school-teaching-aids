# 伙伴图鉴设计（45 种）

> 设计原则：**原创、无 IP 风险**（不使用任何已注册商标的卡通角色）；统一为「发光体 + 学生主色」的视觉体系；分六包，与年级学段的学习内容呼应。
> 代码位置：`frontend/partner-demo.html` 的 `LIB`（第 276–337 行）、`frontend/teacher-dashboard.html` 与 `partner-demo.html` 的 `creature()` DRAW 对象。

## 1. 主题包划分

| 包 | key | 对应学段 | 学习内容呼应 | 数量 |
|---|---|---|---|---|
| 萌系自然 | `cute_nature` | 1–2 年级 | 认识常见动物、感受生命可爱、建立亲近感 | 14 |
| 生命观察 | `life_obs` | 3–4 年级 | 养蚕、种豆、观察蜗牛/蚂蚁、植物生长周期 | 12 |
| 动漫原创 | `anime_original` | 5–6 年级 | 物质与能量、元素概念、抽象科学想象 | 12 |
| 恐龙系列 | `dino_pack` | 全学段 | 古生物、灭绝与演化、考古兴趣 | 3 |
| 星际精灵 | `cosmo_pack` | 全学段 | 宇宙探索、天文现象、科幻想象 | 3 |
| Xiaolong人 | `xiaolong_pack` | 全学段 | 职业认知、原创龙人角色扮演 | 3 |

> ⚠️ **分级只做「默认推荐」，不做强制限制**（对应需求 R18）。学生端顶部标签可自由切换，任意年级可选任意伙伴。
> v0.3.0 新增 3 个系列包（恐龙/星际精灵/Xiaolong人）为全学段开放，不绑定特定年级。

## 3. 视觉与动效规范

| 维度 | 规范 |
|---|---|
| 主色 | 继承学生自定义主色 `students.color`（`#RRGGBB`），保证同类形象在班内可区分 |
| 结构 | 统一「发光体」容器：底部柔光椭圆 + 主体 SVG + 顶部高光 |
| 稀有度 | 普通 `#8FC7FF` ｜ 稀有 `#7FE3C0` ｜ 史诗 `#FFB38A`（仅用于学生端卡片标签色，不影响老师大屏） |
| 呼吸 | `breathe`：`transform: scaleY` 缓动，周期约 3s，幅度 3% |
| 眨眼 | `blink`：眼睑 `scaleY(0.1)`，周期约 4.5s，瞬时 |
| 摇摆 | `wig`：`rotate(±3deg)`，周期约 2.5s，用于「被爱护」状态 |
| 跳动 | `hop`：`translateY(-8px)` 一次，用于签到/答题/点评成功后的即时反馈 |
| 状态 | `wilt`（蔫了，整体降饱和 + 下垂）｜ `injured`（受伤，倾斜 + 灰化）｜ `loved`（被爱护，粉色描边 + 摇摆）｜ `sel`（选中，外发光） |

## 4. 一致性强约束（防回归）

> **`PARTNER_KINDS` 是唯一事实来源。**

- 前端 `LIB` 的 `kind` 必须 ⊆ 后端 `PARTNER_KINDS`，否则认领接口会返回 `partner_kind 非法`。
- 新增伙伴 SOP：
  1. 在 `server/src/routes/students.js` 的 `PARTNER_KINDS` 追加 `kind`；
  2. 在 `frontend/partner-demo.html` 的 `LIB` 追加 `{kind,name,emoji,pack,rarity}`；
  3. 在 `frontend/teacher-dashboard.html` 与 `partner-demo.html` 的 `creature()` 中实现该 `kind` 的 SVG **（缺 SVG 会退化为「蛋」，务必补齐——`duckling` 曾踩此坑）**；
  4. 在 `preview-creatures.html` 同步；
  5. 更新本文件；
  6. 提交并在学生端目视验收。
