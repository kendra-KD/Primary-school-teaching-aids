# 权限分层设计

> 设计原则：**老师绝对权限，学生最小权限**。工具运行在班级智慧白板上，老师登录账号后切换班级使用；学生仅在课间通过设备端与自己的伙伴互动。
> 后端校验为最终防线，前端 UI 隐藏为体验优化——双层防护。

## 1. 角色定义

| 角色 | 身份认证方式 | 使用场景 |
|---|---|---|
| **老师** | 邮箱+密码登录（JWT token） | 大屏驾驶舱（智慧白板常驻），全功能操作 |
| **学生** | 班级码+认领设备令牌（device_token） | 课间/课后在设备端（平板/手机）与自己的伙伴互动 |

## 2. 权限矩阵

### 2.1 老师功能（全部 ✅）

| 功能 | 后端接口 | 前端入口 | 鉴权 |
|---|---|---|---|
| 建班/编辑班级 | POST/PUT /api/classes | 顶栏「➕ 建班」 | JWT |
| 花名册增删改 | POST/PUT/DELETE /api/students | 花名册面板 | JWT + assertOwnsClass |
| **切换班级** | POST /api/classes/:id/verify-switch | 顶栏班级切换器 | JWT + switch_code 验证 |
| 设置切班码 | PUT /api/classes/:id/switch-code | 花名册「🔒 设置切班码」 | JWT + 登录密码验证 |
| 开始/结束上课 | POST /api/lessons/start, /end | 顶栏「📚 上课/下课」 | JWT |
| 点评学生 | POST /api/events | 点评标签 | JWT + lessonToken |
| 录题/批量导入 | POST /api/classes/:id/questions | 录题面板 | JWT |
| 审批换伙伴 | PUT /api/change-requests/:id | 换伙伴申请列表 | JWT |
| 查看带班记录 | GET /api/me/classes | 「我的带班记录」页 | JWT |
| 查看所有班级 | GET /api/classes | 顶栏切换器 | JWT |
| 生成班级码 | POST /api/classes/:id/code | 花名册 | JWT |
| 删除班级 | DELETE /api/classes/:id | 花名册 | JWT |

### 2.2 学生功能（受限 ✅ / 禁止 ❌）

| 功能 | 是否允许 | 说明 |
|---|---|---|
| 认领自己的伙伴 | ✅ | partner-demo 选形象 → POST /api/students/:id/claim |
| 查看自己伙伴主页 | ✅ | loadHome，GET /api/students/:id/activities |
| 课间答题 | ✅ | POST /api/students/:id/quiz（assertDeviceToken 限制只能操作自己） |
| 提交作业/观察 | ✅ | POST /api/students/:id/activity（同上） |
| 给同组同学互动 | ✅（待 R46 完善） | 换伙伴申请，不直接改他人伙伴 |
| ❌ 删除/修改他人伙伴 | ❌ | device_token 只匹配自己，改他人返回 401 |
| ❌ 录题 | ❌ | /api/classes/:id/questions 需 JWT，学生无 token |
| ❌ 审批换伙伴申请 | ❌ | 需 JWT |
| ❌ 切换班级 | ❌ | 前端无切班入口；后端 verify-switch 需 JWT |
| ❌ 查看其他班级信息 | ❌ | /api/join/:code 只返回该 code 班级；/api/classes 需 JWT |
| ❌ 查看老师带班记录 | ❌ | /api/me/classes 需 JWT |
| ❌ 查看花名册全量 | ❌ | /api/classes/:id/students 需 JWT |
| ❌ 设置切班码 | ❌ | 需 JWT + 登录密码 |

## 3. 双层防护机制

### 3.1 后端校验（最终防线）

```
老师功能 → JWT token 校验（fastify.authenticate）+ assertOwnsClass/assertOwnsStudent 归属校验
学生功能 → device_token 校验（assertDeviceToken，只能操作 token 对应的学生）
```

**关键设计**：学生端的所有写操作（答题/活动）都走 `assertDeviceToken`，该函数校验 `X-Device-Token` 头与 URL 中的 studentId 必须匹配。学生拿不到其他学生的 device_token，因此无法操作他人数据。

### 3.2 前端 UI 隔离（体验层）

- **老师端（teacher-dashboard.html）**：全部功能入口可见，需登录
- **学生端（partner-demo.html）**：仅显示认领/答题/作业/伙伴主页，无任何管理功能入口
- 两端文件物理隔离，学生端不加载老师端代码

## 4. 安全红线

1. **device_token 不跨设备共享**：认领时签发，存 localStorage，换设备需重新认领
2. **切班码不公开展示**：大屏只显示「已生成」，不显示明文，防止学生看到后切班
3. **学生端无管理入口**：花名册/录题/审批/切班/带班记录均不在 partner-demo 出现
4. **JWT token 有效期**：登录态过期需重新登录，防止 token 泄露后被长期利用
