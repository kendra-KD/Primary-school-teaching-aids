> 主理人：卓立行（独立开发操盘手）｜ 团队：独立产品团队
> 日期：2026-08-24 ｜ 状态：Phase 1 老师大屏高保真原型已完成，可进入 MVP 开发评估

## 一、产品定位与命名

**一句话定位**：给每个孩子一个"值得负责的生命伙伴"，把科学课的正向行为变成全班共同养护的家园。

**命名建议（沿用主品牌）**：
- 主名 **成长星球**，对外称 **「成长星球·科学班生态」**。
- 理由：继承你原文档的资产认知，副标题用"科学"锁定学科，与通用积分工具划清边界。
- 备选：奇趣小生态 / 探秘星球（偏学生向，老师端识别弱，不优先）。

**目标用户**：小学科学老师（主操作者）＞ 小学生（被激励者）＞ 家长（后置共育）。

---

## 二、科学学科专属机制（核心护城河）

这是本工具**不能被希沃/ClassDojo 直接替代**的根本原因——通用工具只有"纪律/作业/助人"，而本清单有 6 条**只有科学课才有的行为**。

### 正向行为标签（12 条，预置、零备课）

| 分组 | 标签 | 生态反馈 | 分值 |
|---|---|---|---|
| 思维 | 提出好问题/大胆猜想 | 头顶冒"?"→开花 | +2 |
| 思维 | 完整表达探究结论 | 成长+→进化一级 | +3 |
| 实验 | 规范操作实验 | 活力+发光蹦跳 | +2 |
| 实验 | 安全提醒/保护同伴 | 活力+ | +2 |
| 观察 | 认真观察并记录 | 成长+长新叶 | +2 |
| 观察 | 科学阅读/资料打卡 | 成长+长知识叶 | +1 |
| 生命 | 爱护实验生物/植物 | 伙伴回以"拥抱"，生命值+ | +3 |
| 合作 | 小组合作探究 | 伙伴间长连接藤蔓 | +2 |
| 合作 | 帮助同学/分享发现 | 连接藤蔓 | +2 |
| 工程 | 创新小制作/工程挑战 | 进化解锁新形态 | +3 |
| 责任 | 主动整理/归位器材 | 活力+ + 星球整洁度↑ | +2 |
| 责任 | 坚持长期观察(连 N 天) | 进化+稀有装扮 | +3达成 |

### 负向（可恢复、不羞辱）

| 行为 | 反馈 | 说明 |
|---|---|---|
| 不安全操作 | 伙伴"蔫了"垂头 | 明日养回 |
| 破坏/怠慢生命 | 伙伴"受伤"贴创可贴 | 需"照料"动作恢复（生命科学专属） |
| 不整理器材 | 星球整洁度↓ | 集体可恢复，不点名 |

> ⚠️ 设计红线：负面用"状态恢复"而非"死亡/扣分"。低龄羞耻感会反噬兴趣。

## 三、多班级管理方案（一等公民）

科学老师跨年级跨班排课，多班级是刚需而非附加项：

1. **极速切班**：登录后班级以卡片墙呈现，一键进班，localStorage 记住上次班级，课前 30 秒完成。
2. **数据严格隔离**：每班独立命名空间/数据，切换即加载该班专属生态，零串扰。
3. **班级独立主题**：每班伙伴形态与进度阶段不同（如三(1)蚕宝 / 四(2)小苗 / 五(1)小鱼+晶簇 / 六(3)蜗牛+蝴蝶），预置学科主题，不强制统一。
4. **弱网容错**：Web 方案本地缓存点评，断网也能评，联网再同步（科学教室网络不稳）。

## 四、功能清单与信息架构（老师大屏驾驶舱）

```
成长星球（老师大屏 Web）
├─ 顶部栏：班级切换 + 星球阶段 + 今日生态值 + 课堂计时器 + 集体进度环
├─ 主视觉区：全班生态星球全景（伙伴大色块简形，亮=活跃/垂=蔫/爱心=被爱护/创可贴=受伤）
├─ 右侧：光荣榜/共生榜（最繁荣小组·最佳搭档·最爱提问·生命守护星·星球整洁度）
├─ 底部栏：一键点评面板（12 科学标签，点伙伴→点标签两步）
└─ 浮层：个体成长卡（进化轴 + 预置装扮 + 关系藤蔓网）
```

**界面模块**
1. 生态星球主视觉（远距可读）
2. 一键点评面板（零打字）
3. 光荣榜/共生榜（只表扬成长与共生）
4. 个体成长卡浮层
5. 集体目标进度环（荒芜→绿意→繁荣）

## 五、技术形态选型

| 形态 | 结论 |
|---|---|
| **Web 大屏网页（首版）** ✅ | 零安装、大屏浏览器直开、低成本、易迭代、可本地缓存做弱网容错 |
| 微信小程序（后置） | 承接学生端养成 + 家校同步，扫码即用 |
| 独立 App（不推荐首版） | 成本/维护最高，资金时间不允许 |

**存储**：MVP 用 IndexedDB 本地 + 可选轻云服务，先不建复杂后端。
**动效**：复用 CSS/SVG 动效（开花/藤蔓/蹦跳），不自研引擎。

## 六、MVP 范围与 Roadmap

### MVP 必做（首版老师大屏）
班级切换 + 数据隔离 + 生态墙 + 科学点评面板 + 光荣榜 + 成长卡浮层 + 进度环 + 音效动效 + 弱网缓存。

### 后置（P2+）
学生端养成界面、家校/家长门户、公益种真树、标签自定义后台、数据周报导出、年级横向视图、装扮商城。

| 阶段 | 内容 | 产出 |
|---|---|---|
| Phase 0 ✅ | 需求对齐+方案+参考拆解 | 原文档 |
