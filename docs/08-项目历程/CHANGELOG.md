## [v0.3.2] — 2026-09-13 · 系统性反馈收口（入班码安全/权限分层/形象重做）

### 安全
- **R70 入班码不在大屏显示**：移除上课后大屏展示入班码逻辑（学生看到后能切班）。改为**老师自设固定切班码**（经 AskUserQuestion 选方案A，放弃方案B「自动发老师邮箱」因需改注册流程加邮箱验证码过重）。切班时 `GP.pinPrompt()` 弹窗输入验证。`classes.switch_code` 字段 bcrypt 哈希存储。
- **R71 切班码可实时修改**：班级设置「修改切班码」需先验证老师登录密码（`bcrypt.compare`），通过后才更新 `switch_code`，防止密码泄露后数据被改。`PUT /api/classes/:id/switch-code`。
- **R72 权限分层系统**：输出《[权限分层设计](../03-产品设计/权限分层设计.md)》——老师绝对权限（建班/花名册/录题/审批/带班记录/点评/大屏）vs 学生受限（仅与自己的伙伴互动、同组有限互动、不能删改他人伙伴/录题/审批/查其他班级/带班记录）。前端按 `user.role` 渲染不同 UI，后端 `assertOwnsStudent` + 路由级鉴权兜底。

### 修复
- **R73 切班后学生名单不刷新**：`localStorage.gp_me` 存旧 `classCode`，URL `?code=新码` 进来时 `restoreHome` 跳过重新加载。init() 增加 URL code 与 saved.classCode 不一致时 `removeItem('gp_me')` 清旧记录。
- **R74 学生自选页跳转简化**：`fresh=1` 入口直接 `loadClass()` 进选伙伴流程，不再弹「互动/认领」二选一；不带 `fresh` 直接 `restoreHome()` 进上次伙伴主页。
- **R75 点击「认领我的伙伴」返回 Bad Request**（INC-011）：前端 LIB 有 `brachio`/`stego`/`raptor`/`comet_tail`/`pulsar_star` 等新 kind，后端 `PARTNER_KINDS` 未同步 → 400。后端追加 5 kind，前后端 52:52 一致。

### 变更
- **R76 伙伴形象视觉重做**（Q版立体渐变风，参考宝可梦/兽妈）：
  - **P1 基底函数重写**：`creature()` 增加 4 个 radialGradient（主体/腹部/高光/眼睛，按 type 唯一 uid 避免冲突）+ `hi()` 高光椭圆 + `face()` 大眼双层白色高光+粉色腮红 + `mammal()`/`fishBody()` 立体化。
  - **P2 包合并**：`cute_nature` + `life_obs` → `natural_spirit`（26 处 pack 字段 sed 批量替换 + 映射更新）。
  - **P3-P6 全部 50 种形象 SVG 重写**：全部用 `url(#gB{uid})`/`url(#gW{uid})`/`url(#gE{uid})` 渐变 + `hi()` 高光。
  - **P5 扩充种类**：恐龙 3→6（brachio/stego/raptor），星际精灵 3→5（comet_tail/pulsar_star）。伙伴总数 45→50。
  - **P7 主色板扩充**：SWATCHES 10→22 色（粉/橙/绿/蓝/紫/米/棕 7 色系）。
  - **P8 同步 teacher-dashboard.html**：两文件 creature() 保持同款（165 行），Python 脚本精确替换。
  - **P9 同步后端 PARTNER_KINDS**：追加 5 kind，前后端 52:52 一致。

### 文档
- 需求清单新增 **R70–R76**（共 76 条，统计更新为 **64 ✅ / 1 🟡 / 10 🔴 / 1 ⏸**）。
- 新增《[权限分层设计](../03-产品设计/权限分层设计.md)》设计文档。

## [v0.3.0] — 2026-09-12 · 安全加固 + 动效/穿戴/形象扩充（批次1+2）

### 安全
- **R54 PIN 安全加固**：切班**永远需 PIN**（旧版仅授课中验证，未授课可直接切）；顶栏完全隐藏 PIN（旧版「点击查看」显示 3 秒，下课后学生仍能看）；新增右下角隐蔽「🔑 查看 PIN」按钮（仅授课中显示，3 秒后隐藏）。
- **R61 精致解锁面板**：新增 `GP.pinPrompt(title)` Promise 化暗色卡片式 PIN 输入面板，替换浏览器原生 `prompt`；支持 Enter 提交 / Escape 取消 / 遮罩点击取消；`GP.pinShake()` 错误时抖动+红边+清空。同时服务于切班验证和 `applyTag` 授课锁定。

### 新增
- **R55 学生自选页双入口**：花名册浮层拆为「🎒 首次认领入口」（带 `fresh=1`，老师给新学生认领）和「📱 学生互动入口」（不带 `fresh`，学生课间答题/交作业直达伙伴主页）。
- **R56 动效强化**：粒子 1→5 个、持续 0.9s→2.5s、带随机方向偏移；闪光 0.9s→2.2s；`s.decor` 花叶永久佩戴（星球墙恒久可见，非只闪一下）。
- **R57 计时全屏放大**：计时器加 ╌ 全屏按钮，`position:fixed;inset:0` 覆盖整屏，数字 `clamp(8rem,22vw,20rem)` 响应式超大字号，支持点击暂停/继续、Esc 退出，适用于投影做考试倒计时。
- **R58 装扮穿戴**：学生对象新增 `wearing` 字段，成长卡装扮点亮后可点击「穿戴/卸下」，持久化到 `localStorage`，`wearSVG()` 在伙伴头顶叠加帽子/眼镜/围巾/皇冠等 SVG。
- **R59 题库批量导入**：录题面板加「📋 批量导入」折叠区，支持粘贴多行文本（`题干|A|B|C|D|答案`）或上传 CSV/TXT 文件，逐条解析 POST，显示成功/失败数+格式错误行。
- **R60 伙伴形象扩充**：新增 9 种原创 SVG 形象（恐龙系列 3 + 星际精灵系列 3 + Xiaolong人系列 3），学生端可见可选，全部原创无动漫版权风险。

### 文档
- 需求清单新增 **R54–R61**（共 61 条，统计更新为 **57 ✅ / 1 🟡 / 3 🔴**）。
- 伙伴图鉴设计文档扩充至 45 种（新增 9 种，3 个系列包）。

## [v0.2.4] — 2026-09-11 · 删除修复 + 学生作业入口 + 老师互动明细

### 修复
- **删除学生报 Bad Request（400）**（R42 / INC-007）
  - 根因：前端 `GP.api()` 对无 body 的 `DELETE` 也强制 `Content-Type: application/json`，Fastify 5 抛 `FST_ERR_CTP_EMPTY_JSON_BODY`。
