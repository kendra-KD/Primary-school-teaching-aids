## [v0.2.2] — 2026-09-11 · 稳定性修复

### 修复
- **登录返回 Internal Server Error**（R23 / INC-005）：`server/src/index.js` 的 `authenticate` 钩子中 `reply.code(401).send()` 缺少 `return`，钩子返回后路由处理器继续执行、访问 `req.user.sub` 抛 `TypeError` 被兜成 500。补上 `return`。
- 登录成功后云端同步失败不再被误报为「登录失败」（`GP.login()` 的 `pullAll()` 加 try/catch）。

**提交**：`91feb29`

## [v0.2.1] — 2026-09-10 · 生态与互动

### 新增
- **学生与伙伴互动闭环**（R19/R30/R31）：学生端「我的伙伴」主页，支持每日签到（+1，限每日一次）、课间答题（答对 +2）、观察记录（+1）；生态值累计驱动伙伴成长。
- **后端** `student_activities` 表 + 免登录接口 `POST /api/students/:id/activity`、`GET /api/students/:id/activities`；分值由服务端按 `kind` 决定，防前端刷分。
- **老师大屏 15 秒实时轮询**：学生课后互动自动反映到老师大屏；切后台暂停轮询。
- 伙伴图鉴多元化：**38 种独立 SVG 形象**（补齐 `duckling`），含呼吸 / 眨眼 / 摆动 / 点赞跳动动画与 `wilt`/`injured`/`loved`/`sel` 状态。
- 学生端图鉴标签：全部 / 萌系自然 / 生命观察 / 动漫原创，**取消「每年级只能选某类图鉴」的限制**（R18）。
- 底部加分 dock 支持收起/展开，不再遮挡右侧榜单（R21）。

### 修复
- **老师大屏长时间转圈打不开**（R26 / INC-003）：Umami 统计脚本 TTFB 2.46s 且带 `defer` 阻塞首屏；改为 `window.onload` 后动态注入，并为 `GP.api()` 增加 12s 超时、初始化增加「正在加载星球…」提示。
- **删除学生/班级返回 500**（INC-004）：`partner_claims`、`submissions` 外键缺 `ON DELETE CASCADE`，迁移脚本重建约束。
- 建班后 `class_code` 未返回。

### 变更
- 建班弹窗年级下拉简化为纯数字 1–6，去掉「图鉴风格」文案（R22）。
- 登录密码框增加 👁️ 明文预览切换（R24）。
- `KIND2TYPE` 映射表废弃，`pullState` 直接传 `partner_kind`。

### 文档
- 同步线上 certbot 管理版 Nginx 配置到仓库存档。

## [v0.1.0] — 2026-09-05 · 老师端可用

### 新增
- **老师端核心链路**（R01–R07）：两步点击课堂点评、12 条科学学科专属标签、即时特效、全班实时大屏（伙伴墙 + 光荣榜 + 班级进度环）、关系藤蔓网、撤销点评、负向行为可恢复。
- 老师账号登录（JWT，30 天）+ 云端同步层（R08）；未配置云端时自动降级 localStorage。
- 后端 Fastify 5 + PostgreSQL API（auth / classes / students / events）。
- Docker 一键部署 + 宿主 Nginx 同域反代 `/api` + certbot HTTPS（ADR-002）。
- 独立 `gp-db` 实例（端口 5434），不污染同机 umami-db / MealPick（ADR-003）。

### 修复
- **登录按钮不显示**（INC-002）：`build-frontend.sh` 的 sed 全局替换把 `if(GP_API==='__GP_API_BASE__')` 也替换掉，导致 `GP_CLOUD` 恒为 false；改为只精确替换赋值语句。
- 改用宿主 Nginx 反代，移除抢 80 端口的 `gp-web` 容器。
