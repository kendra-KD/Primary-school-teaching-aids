# 术语与角色

## 1. 角色定义

| 角色 | 真实对象 | 系统身份 | 能做什么 | 不能做什么 |
|---|---|---|---|---|
| **老师** | 李钰琳老师（试点） | `teachers` 表记录，JWT 登录（30 天有效） | 建班 / 改班 / 删班；批量导入与维护花名册；课堂点评与撤销；看全班实时状态与光荣榜；换班级码 | 只能访问自己 `teacher_id` 名下的班级与学生（`assertOwnsClass` / `assertOwnsStudent` 强制校验） |
| **学生** | 1–6 年级小学生 | **无账号**，凭 `student_id`（UUID）直接写库 | 输班级码入班、选自己名字、认领/更换伙伴、签到、答题、观察记录 | 不能点评他人、不能改分数（分值全部服务端定）、不能查看他人活动明细 |
| **运营 / 研发** | 项目维护者 | 服务器 SSH | 部署、迁移、建老师账号、看日志、看 Umami | 不直接改生产数据库里的学生数据（除非救援） |

> **为什么学生端免登录？** 小学生记不住账号密码，且课堂时间宝贵。风险控制手段是：学生端写接口只开放「无害且不可刷分」的动作（认领、签到、答题、观察），分数由服务端按动作类型给定，且签到按天去重。

## 2. 领域术语表

| 术语 | 英文 / 代码字段 | 定义 |
|---|---|---|
| **成长星球** | Growth Planet | 整个产品名；也指老师大屏中央那颗由全班伙伴构成的星球 |
| **科学班生态** | — | 班级层面的生态值系统，全班共同把星球从「荒芜」养到「繁荣」 |
| **伙伴** | partner / `partner_kind` | 每个学生认领的生命伙伴形象。共 38 种原创 SVG，无 IP 风险 |
| **图鉴** | codex | 学生端可浏览的伙伴全集，按主题包分标签（全部 / 萌系自然 / 生命观察 / 动漫原创） |
| **主题包** | `theme_pack` | 早期按年级分层的推荐分组：`cute_nature`(1–2) / `life_obs`(3–4) / `anime_original`(5–6)。**现已降级为「推荐」，不再限制学生选择** |
| **点评** | event | 老师点「伙伴 + 科学标签」产生的一条记录，写入 `events` 表 |
| **标签** | label / `label_key` | 12 条科学学科行为，定义在 `server/src/labels.js`，含分值 `delta`、是否计入生态 `eco`、是否长藤蔓 `vine`、前端特效 `fx` |
| **成长值** | growth | 学生的累计得分 = 老师点评分值 + 学生自主活动分值 |
| **进化阶段** | `partner_stage` | 0–3 阶，阈值 `[0, 12, 35, 70]`，由 growth 决定 |
| **活力值** | `vitality` | 0–100，初始 50；正向点评 +`delta*3`，负向 −`delta*3`；< 30 显示「蔫了」 |
| **蔫了 / 受伤** | droop / hurt | 负向行为导致的伙伴可视化状态。**设计上可恢复**：老师点「照料」（`PUT /api/students/:id {care:true}`）或正向点评即可养回 |
| **关系藤蔓** | vine / `vines` 表 | 合作类行为在两名同学之间生成的连线，可视化班级关系网 |
| **班级生态值** | `classes.eco_value` | 只累加正向点评，驱动班级阶段 |
| **班级阶段** | wild / green / bloom | 荒芜 / 绿意 / 繁荣，阈值 0 / 120 / 360 |
| **班级码** | `class_code` | 班级 id 前 6 位十六进制，天然唯一；学生凭码入班。可一键重生成（原码立即失效） |
| **光荣榜** | board | 大屏右侧榜单：成长之星 Top5、提问之星、生命守护者、整洁度 |
| **加分 dock** | dock | 大屏底部标签快捷栏，可收起/展开（避免遮挡右侧内容） |
| **学生活动** | `student_activities` | 学生自主行为记录：`checkin`(签到) / `quiz`(答题) / `observe`(观察) / `homework`(作业) |
| **云同步层** | GP / `GP_CLOUD` | 前端内置的同步能力。未配置 `GP_API_BASE` 时退化为纯 localStorage 本地模式，功能不丢 |
| **Umami** | — | 自托管访问统计，用于回答「有哪些人在用」 |
| **试点老师** | — | 四川小学科学老师李钰琳，账号 `luyulin@mealpick.me` |

## 3. 状态机

### 3.1 学生成长阶段

```
stage 0 (稚嫩) ──12──> stage 1 (成长) ──35──> stage 2 (强壮) ──70──> stage 3 (成熟)
```

### 3.2 伙伴状态（互斥优先级）

```
hurt（受伤，负向标签 hurt_life 触发）
  > droop（蔫了，vitality < 30）
    > active（正常）
       > loved（被爱护，独立标记，可叠加显示）
```

### 3.3 班级生态阶段

```
荒芜 (0) ──120──> 绿意 (120) ──360──> 繁荣 (360，封顶显示)
```

## 4. 命名约定

| 层 | 约定 | 示例 |
|---|---|---|
| 数据库表/字段 | 小写下划线，复数表名 | `student_activities.partner_kind` |
| API 路径 | `/api/<资源复数>`，学生端免登录接口不加 auth 钩子 | `POST /api/students/:id/activity` |
| 伙伴代号 | 小写下划线，动物/植物/元素语义 | `bunny`、`shy_plant`、`fire_sprite` |
| 前端云函数 | `GP.xxx()` | `GP.login()`、`GP.api()`、`GP.pullAll()` |
| 提交前缀 | `[feat]` `[fix]` `[ui]` `[docs]` `[chore]` | `[fix] 鉴权钩子缺失 return…` |
