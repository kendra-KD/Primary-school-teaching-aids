# 里程碑与版本

## 1. 版本节奏

本项目采用**「原型先行 → 小步快跑 → 单点验证」**的节奏，不做长周期大版本。每个可交付批次即一次 `Phase`，对应若干次提交与一次线上部署。

| 阶段 | 时间 | 主题 | 交付物 | 状态 |
|---|---|---|---|---|
| **Phase 0** | 2026-08-24 | 设计先行 | 调研报告、老师访谈提纲、设计稿、后端部署方案、前端原型 | ✅ 完成 |
| **Phase 1** | 2026-09-05 | 老师端可用 | Fastify API + PostgreSQL + Docker 部署 + 云同步层 + 首次线上 HTTPS | ✅ 完成 |
| **Phase 1.5** | 2026-09-07 | 学生端接入 | 班级码入班 + 伙伴认领 + 36 种伙伴 + 大屏 UI 重写（治愈科技光感）+ Umami 埋点 | ✅ 完成 |
| **Phase 2** | 2026-09-10 | 生态与互动 | 38 种独立 SVG + 动画 + 学生互动闭环（签到/答题/观察）+ 大屏 15s 实时轮询 + 三项 UI 优化 | ✅ 完成 |
| **Phase 2.1** | 2026-09-11 | 稳定性修复 | 登录 500 修复、批量导入 500 修复、鉴权钩子加固 | ✅ 完成 |
| **Phase 3** | 待定 | 真实试用验证 | 李老师班级真实名单灌库 → 两周课堂试用 → 反馈迭代 | ⏳ 进行中 |
| **Phase 4** | 待定 | 学科内容深化 | 课间知识问答题库、知识点挂接、作业入口、周报 | 📋 规划中 |
