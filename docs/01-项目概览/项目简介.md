# 项目简介

## 1. 一句话定义

**成长星球 · 科学班生态** 是一套面向小学科学课堂的轻量教学辅助工具：每个孩子认领一个「生命伙伴」，全班伙伴组成一颗会生长的「生态星球」；老师在课堂上用两步点击完成点评，伙伴当场产生生态反馈（开花 / 发光 / 长叶 / 藤蔓 / 进化），把「科学课堂的行为」变成「看得见的成长」。

## 2. 要解决的问题

| 痛点 | 现状 | 本项目的解法 |
|---|---|---|
| 课堂正向行为难以及时强化 | 口头表扬转瞬即逝，学生缺乏持续动机 | 点评即反馈：两步点击，伙伴当场动画回应 |
| 通用积分工具「不认科学」 | ClassDojo / 希沃等只有「举手、认真」这类通用项，记不下学科特性 | **12 条科学学科专属标签**，直接对应课标行为 |
| 负面行为管理容易变成羞辱 | 扣分导致对抗、贴标签 | 负向标签设计为**「恢复」组**（可养回来、次日复原），不羞辱、不排名靠后 |
| 微信/纸质评价没法沉淀 | 一学期的行为数据无法回顾 | 数据入库，支持光荣榜、生态值、长期趋势（规划中） |
| 课堂 40 分钟时间宝贵 | 复杂工具老师不会用 | 零安装、零培训：打开网页 → 点伙伴 → 点标签，两步完成 |

## 3. 核心机制

### 3.1 两条主链路

```
【老师侧·课堂点评链】
  打开大屏 → 点某个学生的伙伴 → 点一个科学标签
      → 服务端按标签定分（前端不可传分）
      → 学生成长值 += delta，活力值变化，伙伴可能进化（0→3 阶）
      → 若为合作类标签：两名同学之间长出一条「关系藤蔓」
      → 班级生态值 += delta（只加正向），推动班级阶段 荒芜→绿意→繁荣

【学生侧·自主互动链】
  扫入班码/输班级码 → 选自己名字 → 认领伙伴（38 种自选，可换）
      → 进入「我的伙伴」主页
      → 每日签到(+1) / 课间答题(+2/答错0) / 观察记录(+1) / 提交作业(+3，接口已就绪)
      → 生态值累积 → 老师大屏 15s 轮询自动反映
```

### 3.2 数值体系

| 概念 | 规则 | 来源 |
|---|---|---|
| 学生成长值 growth | `events.delta` 之和 + `student_activities.points` 之和 | `server/src/routes/events.js` |
| 伙伴进化 stage | 阈值 `[0, 12, 35, 70]` → 0~3 阶 | `server/src/labels.js` |
| 活力值 vitality | 初始 50，每次点评 `±delta*3`，钳制 0~100；< 30 判为「蔫了」 | `labels.js` + `events.js` |
| 班级生态值 eco_value | 只累加正向 `delta` | `events.js` |
| 班级阶段 | 荒芜(0) / 绿意(120) / 繁荣(360) | `labels.js` |
| 关系藤蔓 | 合作类标签（`cooperate` / `help_mate` / `safety_remind`）触发，同一对学生只长一条 | `events.js` + `vines` 表 |

### 3.3 12 条科学标签（护城河）

| 分组 | 标签 | 分值 | 触发效果 |
|---|---|---|---|
| 思维 | 提出好问题 / 大胆猜想 | +2 | bloom |
| 思维 | 完整表达探究结论 | +3 | evolve |
| 实验 | 规范操作实验 | +2 | glow |
| 实验 | 安全提醒 / 保护同伴 | +2 | glow + **藤蔓** |
| 观察 | 认真观察并记录 | +2 | leaf |
| 观察 | 科学阅读 / 资料打卡 | +1 | leaf |
| 生命 | 爱护实验生物 / 植物 | +3 | hug |
| 合作 | 小组合作探究 | +2 | **藤蔓** |
| 合作 | 帮助同学 / 分享发现 | +2 | **藤蔓** |
| 工程 | 创新小制作 / 工程挑战 | +3 | evolve |
| 责任 | 主动整理 / 归位器材 | +2 | tidy |
| 责任 | 坚持长期观察 | +3 | evolve |
| 恢复 | 不安全操作 | −2 | droop（可恢复） |
| 恢复 | 怠慢实验生物 / 植物 | −3 | hurt（可恢复） |
| 恢复 | 器材未归位 | −1 | mess（可恢复） |

## 4. 系统组成

| 组件 | 路径 | 说明 |
|---|---|---|
| 老师端大屏 | `frontend/teacher-dashboard.html` | 单文件高保真原型（约 1476 行，含 38 种 SVG 伙伴、动画、云同步层）；生产构建产物在 `deploy/frontend-built/` |
| 学生端 | `frontend/partner-demo.html` | 单文件（约 631 行）：伙伴图鉴自选 + 我的伙伴主页 + 互动区 |
| 后端 API | `server/` | Node 22 + Fastify 5 + pg，10 个路由文件；无 ORM，裸 SQL + 参数绑定 |
| 数据库 | `deploy/growth-planet-init.sql` / `-migrate.sql` | PostgreSQL 14，7 张表 |
| 部署 | `deploy/growth-planet-docker-compose.yml` | gp-db(5434) + gp-api(3100)，前端与反代交给宿主 Nginx |

## 5. 明确的边界（当前不做）

- ❌ 不做 App / 小程序 —— 课堂场景用浏览器 + 大屏投影最省事
- ❌ 不引入前端框架与构建链 —— 单文件 HTML 换电脑双击即用，弱网也能跑
- ❌ 不做通用积分工具 —— 只做科学学科
- ❌ 不采集隐私 —— 只存姓名 + 课堂行为，无手机号、无头像上传、无定位
- ❌ 不做班级排行榜羞辱 —— 光荣榜只放正向，负向不出榜
