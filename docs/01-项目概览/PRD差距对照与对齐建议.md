### 🟡 有差异 / 部分覆盖（4 条）

#### PRD R03 → 默认「今日亮点/进步之星」非总榜
- **现状**：大屏光荣榜按成长值正向排序，无「今日亮点/进步之星」专属默认位。
- **PRD 验收标准**：默认展示「今日亮点/进步之星」而非任何总榜。
- **差距**：需加一个「今日亮点」卡片区（老师一键标记某学生当日亮点行为），光荣榜退为次级展示。
- **建议编号**：R62（新增）。

#### PRD R05 → 伙伴状态正向化改造
- **现状**：负向标签触发 `droop`（蔫了）/`hurt`（受伤），`R07` 设计为「可恢复、不羞辱」，但状态名仍为负面表达。
- **PRD 验收标准**：无「枯萎/需照料🥀」等负面表达，「未互动超 3 天」显示为「伙伴想你了/想晒太阳」正向召唤；成长值架构层禁止减法。
- **差距**：
  1. `droop`/`hurt` 状态文案需改为正向（如「伙伴想晒太阳了」「伙伴等你回来」）。
  2. 离线 3 天正向召唤未实现。
  3. 负向标签 delta 仍为负数（PRD 要求架构层禁止减法——可改为「正向分暂时搁置、不倒扣」）。
- **建议编号**：R63（正向化改造，P0）。

#### PRD R10 → 监护人知情同意书模板
- **现状**：R36 隐私政策（7 章节）已上线，学生端首次进入有 banner。
- **PRD 验收标准**：试点开班前就绪，覆盖数据用途、保存期限、删除权。
- **差距**：缺一份可打印/签字的「监护人知情同意书」模板文档（PDF/Word），面向家长发放。
- **建议编号**：R64（知情同意书模板，P0）。

#### PRD R11 → 伙伴新形态解锁线（3 档）+ 教师手动「今日亮点」
- **现状**：R15/R16 已有 45 种形象 + 0-3 阶进化（阈值 12/35/70），R58 已实现装扮穿戴。
- **PRD 验收标准**：成长值达阈值自动解锁新形态 + 庆祝动画；教师一键设置今日亮点。
- **差距**：
  1. 现有 0-3 阶是同形象的缩放/发光，非「解锁新形态」（PRD 要求跨形态解锁，如绿芽→幼苗→花朵→果实是 4 个不同 SVG）。
  2. 庆祝动画未做（现有 hop/spark 是点评反馈，非解锁庆祝）。
  3. 教师手动「今日亮点」未实现（与 R03 黄色行同源）。
- **建议编号**：R65（伙伴形态解锁线 + 庆祝动画，P1）。

### 🔴 未覆盖（4 条）

#### PRD R06 → AI 题库生成
- **PRD 验收标准**：教师粘贴本课教学要点（≤500 字），60 秒内产出 8-12 道中文口头抢答题，可逐题删除/重生成、结果可复用；先用「模板题 + LLM 单次调用」简化版。
- **现状**：R33/R59 已实现手工录题 + 批量导入，但**无 AI 自动生成**。
- **缺口**：需接入 LLM（项目已有 ANTHROPIC_BASE_URL 基建），输入教学要点 → 输出结构化题目 JSON → 写入 questions 表。
- **建议编号**：R66（AI 出题简化版，P0，PRD 核心闭环 B）。
- **技术路径**：Fastify 加 `POST /api/classes/:id/questions/ai-generate`，body `{points}`，调 LLM 生成 JSON 数组，前端预览编辑后批量入库。

#### PRD R07 → 课堂问答互动：大屏发布题目 + 口头/举手答题 → 答对喂养
- **PRD 验收标准**：题库发布后教师点选举手学生，答对点「喂养」，该学生伙伴 3 秒内大屏即时反馈；错答不惩罚、仅不加分。
- **现状**：R47 课间答题是**学生端自助答题**（学生用设备抽题→选答→服务端判分）。
- **差距**：PRD 模式是**大屏出题 + 老师点选答对学生喂养**（零学生设备），与现有学生端自助模式不同。
- **建议编号**：R67（大屏出题 + 口头答题 + 老师喂养模式，P0）。
- **注意**：这与现有 R47 学生端答题是两套模式，可并存或择一，取决于 §2 方向性分歧决策。

#### PRD R13 → 随机点名抽选
- **PRD 验收标准**：一键随机抽选，动画公平可复现。
- **现状**：未实现。
- **建议编号**：R68（随机点名，P1）。
- **技术路径**：大屏加「🎲 随机点名」按钮，`Math.random` + CSS 转盘动画 + 可复现种子（日期+班级码 hash）。

#### PRD R14 → 动物伙伴第二进化线 + 班级投票选形态
- **PRD 验收标准**：教师发起全班投票，多数票决定本学期新伙伴线。
- **现状**：R60 新增了恐龙/星际精灵/Xiaolong人 9 种，但无「班级投票选形态」机制。
- **建议编号**：R69（班级投票选伙伴线，P1）。

### ⚠️ 方向性分歧（2 条，需产品负责人决策）

#### 分歧①：零学生设备 vs 现有学生端

| 维度 | PRD 定位 | 现有实现 |
|---|---|---|
| 学生设备 | **零学生设备**（教育部严禁手机进课堂 + 息屏行动） | 完整学生端 `partner-demo.html`（认领/签到/答题/观察/提交作业/伙伴点击互动） |
| 答题模式 | 大屏出题 + 口头/举手 + 老师喂养 | 学生端自助抽题 + 服务端判分 |
| 合规依据 | PIPL 28/31 条 + 未成年人保护法，学生 14 岁以下 | 学生端有 device_token，但学生用设备本身触红线 |

**冲突点**：PRD 把「不做学生设备端」列为 Non-goal 第 3 条（硬约束），但现有项目已投入大量精力建成学生端并上线（R14/R19/R31/R32/R43/R45-R47 等 10+ 条需求都围绕学生端）。

**决策选项**：

| 选项 | 说明 | 影响 |
|---|---|---|
| A. 坚持 PRD，砍学生端 | 把学生端功能迁回大屏（老师操作） | R14/R19/R31/R32/R43/R45-R47 等已上线功能需重构或废弃 |
| B. 保留学生端，调整 PRD | PRD「零学生设备」改为「可选学生端，课堂内以大屏为主」 | 需修改 PRD Non-goal 第 3 条 + 合规论证（如限定课间/课后用） |
| C. 双模式并存 | 大屏模式（PRD 闭环 B）+ 学生端模式（现有）按场景切换 | 工作量最大但最灵活 |

**建议**：选 B。理由：①学生端已上线且有真实互动闭环，沉没成本大；②学生端限定在「课间/课后」用设备不违反息屏（课堂内仍零设备）；③只需在 PRD 中把 Non-goal 从「不做学生设备」改为「课堂内零设备，课间/课后可选学生端」即可对齐。

#### 分歧②：统一「绿芽」起始 vs 45 种自选

| 维度 | PRD 定位 | 现有实现 |
|---|---|---|
| 起始形态 | 统一「绿芽」→ 随成长解锁新形态（R11 三档进化线） | 学生认领时自选 45 种任意形态 |
| 成长叙事 | 「从一株植物到一个生态」叙事升级 | 学生一开始就有动物/精灵/Xiaolong人，无统一起点 |

**冲突点**：PRD 强调「植物最安全为默认起点」+「动物作 P1 扩展」，现有 45 种里动物/精灵占多数，且学生一开始就自选，弱化了「成长解锁」叙事。

**决策选项**：

| 选项 | 说明 |
|---|---|
| A. 回归 PRD | 默认统一绿芽起步，动物/精灵改为成长值达标后解锁 |
| B. 保留自选 | 维持现状，PRD 的「绿芽起步」改为「推荐但不强制」 |
| C. 混合 | 低年级强制绿芽起步，高年级允许自选（呼应 PRD「万物有灵阶段」洞察） |

**建议**：选 C。低年级（1-2）万物有灵阶段用绿芽最有情感联结；高年级（5-6）已脱敏，用自选 + 收集进度维持新鲜感。

## 3. 后续设计参考优先级

基于以上对照，建议按以下顺序推进：

### P0（PRD 核心闭环，必须做）
1. **R66 AI 出题简化版** — PRD 闭环 B 核心，现有手工录题无法替代
2. **R63 伙伴状态正向化改造** — PRD 教育红线，`droop/hurt` 文案改正向
3. **R64 监护人知情同意书模板** — PRD 试点前置条件
4. **R62 大屏「今日亮点」默认位** — PRD 去排名的核心卖点

### P1（试用期必备）
5. **R67 大屏出题 + 口头答题模式** — 取决于分歧①决策
6. **R65 伙伴形态解锁线 + 庆祝动画** — 跨形态解锁替代同形缩放
7. **R68 随机点名** — PRD R13
8. **R69 班级投票选伙伴线** — PRD R14

### 决策项（已拍板 · 2026-09-12）

- ✅ **分歧① 学生端去留 → 选 B**：保留学生端，PRD Non-goal 第 3 条改为「**课堂内零设备，课间/课后可选学生端**」。合规论证：课堂内仍零设备（不违反息屏），学生端限定课间/课后使用。
- ✅ **分歧② 起始形态 → 选 C（全年级自选）**：维持现状，全年级学生认领时均可自选 45 种任意形态。PRD「统一绿芽起步」调整为「**推荐但不强制**」——保留 45 种自选的自由度，弱化「成长解锁叙事」。
  - 影响：R65（跨形态解锁线）**降级为可选**，因「成长解锁叙事」不再是核心，0-3 阶同形缩放进化已满足当前体验。
