## 📌 TL;DR

- 核心目标：用「每位学生专属学习伙伴养成 + 班级小队共同生态」解决小学课堂激励缺乏情感黏性、随年级脱敏的问题；北极星指标 = 周活跃班级数（WAC）。

## 一句话问题定义

帮助【一线小学教师】在【日常课堂激励】场景下，解决【学生参与度不稳定、小红花/积分激励缺乏情感黏性且随年级脱敏】的问题——相比【纸质小红花与工具型积分产品（班级优化大师）】，我们用【每位学生专属的「学习伙伴」养成 + 班级小队共同生态】让激励有陪伴感、不可通胀、去排名羞辱。

## 1. 产品目标（3 个正交目标）

- **G1 学生：让激励有情感黏性且随年级不脱敏**——伙伴成长为不可通胀的解锁式内容（新形态/新故事/新互动），每学期上新；MVP 期以「绿芽→绽放」正向成长线验证情感联结。
- **G2 教师：课中零负担、备课真减负**——课中任何激励操作 ≤3 秒、零配置开箱即用；「上传课堂内容→AI 生成题库」成为教师备课外挂。
- **G3 验证「教师个人即可采用」的轻 Web 模式成立**——WAC 在 5 班试点后 ≥4，全程不触合规红线（不付费、不排名、学生数据最小化）。

## 2. 用户故事

- **US1（低年级主流程）**：作为 1-3 年级班主任，我希望上课时打开大屏全班伙伴墙，点名某学生回答精彩后一键点他的伙伴，3 秒内全班看到那株绿芽明显长了一截——激励即时可见，不用下课再补小红花。
- **US2（备课减负）**：作为数学教师，我希望把「认识钟表」的教学要点粘贴进系统，一键生成 10 道口头抢答题，课堂举手答题、答对喂养伙伴——复习环节不用自己出题。
- **US3（学生体验，间接）**：作为二年级学生，我不碰任何设备，但举手答对后全班大屏上我的伙伴被「浇了水」、小队生态值涨了，我们小队离共同解锁「彩虹花园」只差一点——我会为伙伴和小队更积极表现。
- **US4（高年级留存）**：作为五年级教师，学生对幼稚贴纸脱敏，但会自发比较伙伴形态收集进度（无排名榜、只看解锁内容）——每学期新进化线维持新鲜感。
- **US5（冷启动）**：作为托管班老师，我没有学校采购渠道，但看到同行分享即可自助注册、15 分钟内建好班级开始用。

## 3. 用户研究洞察（来自瑞思）

1. **激励脱敏是最大风险**：静态积分会通胀贬值；伙伴成长必须是「只解锁、不倒扣」的资产式设计，每学期上新内容。
2. **教师工具生死线**：课中操作 <3 秒、零配置可用；「自动生成题库」直击备课痛点，优先级高于学生资料库。
3. **去排名是红线也是卖点**：公开排名羞辱垫底学生已被 ClassDojo 模式广泛验证为问题；默认展示「今日亮点/进步之星」，小队集体目标实证有效。
4. **政策硬约束定形态**：教育部严禁手机进课堂 + 息屏行动 → MVP 必须教师端操作 + 大屏展示，答题走口头/举手。
5. **情感联结有效但有红线**：动物同伴实证强于纯数字（台湾中央大学 N=68 研究，五年级）；绝不用「挨饿/枯萎/死亡」惩罚孩子（家长视为情感要挟）。
6. **伙伴形象路线**：植物最安全为默认起点（现网已实现），动物作 P1 扩展，「从一株植物到一个生态」叙事升级；IP 形象不可行。

用户细分：教师=决策者+使用者+付费方；1-3 年级学生=最佳切入点（万物有灵阶段）；4-6 年级靠进化收集+小队竞争维持；家长=否决者（投诉可让工具进不了班）。

## 5. 数据依据（来自数析）

- **北极星指标**：WAC 周活跃班级数 = 一周内本班真实课堂完成完整使用循环（打开班级页→展示伙伴状态→完成 ≥1 次课堂互动行为）的班级数。试点健康线：1 班第 4 周仍 ≥1；5 班后 WAC≥4（80% 周留存）。
- **AARRR 适配**：获取（每渠道 ≥5 名教师打开）→ 激活（首次课堂激活率 ≥50%、配置 ≤15 分钟）→ 留存（第 2-4 周班级周留存 ≥70%）→ 收入（MVP 不收费）→ 推荐（6 周内 ≥2 名非试点教师经推荐注册，NPS≥40）。
- **MVP 验证假设**（按验证顺序）：H4 上手零培训（首次配置中位 ≤15 分钟，最先验证）→ H2 教师第 4 周仍活跃 → H1 伙伴成长提升课堂参与（2 周 A/B，≥20% 支持、<10% 重审）→ H3 小队驱动协作（教师评分 ≥3.5）→ H5 NPS≥40。
- **合规红线**（PIPL 28/31 条 + 未成年人保护法）：学生为 14 岁以下未成年人 → 自托管 Umami 埋点（数据不出自有服务器）、学生匿名 ID、不采姓名/学号/照片/生物信息、IP 截断、监护人知情同意书、一键清班删数据。

## 7. 关键流程

**闭环 A（课中激励）**：教师上课 → 打开大屏（伙伴墙）→ 观察到正向行为 → 点选学生+激励项（≤3 秒）→ 伙伴 3 秒内成长动画 → 成长值累加 → 小队进度/生态值更新 → 达标解锁集体目标。

**闭环 B（AI 问答）**：教师备课粘贴教学要点 → AI 生成题库 → 教师审核删改 → 课堂大屏发布题目 → 口头/举手答题 → 教师点选答对学生「喂养」→ 伙伴成长 +3 秒反馈。

**离线尾巴（正向召唤）**：3 天未互动 → 大屏显示「伙伴想你了」→ 教师借机点名鼓励 → 互动后召唤解除（只召唤、不惩罚）。

**冷启动**：教师访问落地页 → 免注册试用 → 建班导名单（≤15 分钟）→ 首次课堂使用 → 计入 WAC。

## 8. Non-goals（明确不做什么）

1. **不做个人排行榜（常驻或可开启）**——公开排名羞辱垫底学生是被验证风险，也是班级优化大师被新华社曝光的舆论软肋。
2. **不做任何家长付费、内购、订阅**——一起作业「成长世界」因诱导未成年消费被关闭；「零付费零内购」写入产品宪法。
3. **不做学生设备端**——教育部严禁手机进课堂 + 息屏行动，硬约束。
4. **v1 不做家长端周报**——家长是否决者，屏幕时间焦虑是现实风险。
5. **不接 IP 形象**——版权成本+政策敏感；教师自定义上传仅作 P2 评估。
6. **不碰学校采购/B 端**——定位「教师个人即可采用」，先托管班/兴趣班/小规模私立验证。
7. **不做伙伴负面状态与成长倒扣**——教育专家红线。
8. **v1 不做多教师协作/学校管理后台**——单班单教师粒度即 MVP 范围。
