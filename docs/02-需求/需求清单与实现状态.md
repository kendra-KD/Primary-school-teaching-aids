## 二、已实现需求（明细）

### R01 两步点击课堂点评 ✅
- **原始诉求**：老师上课需要一个能随手加分的工具。
- **实现**：点伙伴头像 → 底部 dock 弹出标签 → 点标签。整个过程无弹窗、无确认框。
- **证据**：`frontend/teacher-dashboard.html`（`applyLabel` 流程）、`POST /api/events`（`server/src/routes/events.js:44`）
- **验证**：线上实点，接口返回 201 + 特效播放。

### R02 12 条科学学科专属标签 ✅
- **实现**：服务端常量表定义，含 `name / group / delta / eco / vine / fx / negative`；前端从 `/api/labels` 拉取。
- **证据**：`server/src/labels.js:5-29`
- **验证**：`GET /api/labels` 返回 15 条（12 条正向 + 3 条恢复组）。

### R03 点评即时视觉反馈 ✅
- **实现**：`fx` 字段驱动 6 类特效（bloom / glow / leaf / hug / evolve / tidy / vine）；CSS keyframes 动画。
- **证据**：`teacher-dashboard.html` 特效函数与 `#vines` SVG 层（第 328 行）。

### R04 全班实时大屏 ✅
- **实现**：`GET /api/classes/:id/state` 一次返回 class + students + board + vines + today_events；前端渲染伙伴墙、光荣榜、进度环。
- **证据**：`server/src/routes/events.js:124-214`

### R05 关系藤蔓网 ✅
- **实现**：合作类标签（`cooperate` / `help_mate` / `safety_remind`）触发 `vines` 表写入，唯一约束保证同一对学生只有一条；大屏 SVG 绘制连线 + 「最佳搭档」卡片。
- **证据**：`events.js:90-97`、`teacher-dashboard.html:712-719, 951`
- **备注**：**这条需求之前没有文档说明老师该怎么用**，本次补充在 [`../03-产品设计/课堂点评与学生互动闭环设计.md`](../03-产品设计/课堂点评与学生互动闭环设计.md#32-关系藤蔓网怎么用)。

### R06 撤销点评 ✅
- **实现**：`DELETE /api/events/:id`，事务内回滚成长值、活力值、生态值，并重算 stage。
- **证据**：`events.js:217-249`

### R07 负向行为可恢复 ✅
- **实现**：负向标签 `delta` 为负、`eco:0`、不进光荣榜；伙伴进入 droop/hurt；`PUT /api/students/:id {care:true}` 恢复 `hurt=false, vitality≥50`。
- **证据**：`labels.js:26-28`、`students.js:92-95`

### R08 登录 + 云同步 ✅
- **实现**：JWT（30 天）；前端 `GP.login()` → 存 token → `pullAll()` 拉班级与状态；班级数据落 localStorage 以便弱网降级。
- **证据**：`server/src/routes/auth.js`、`teacher-dashboard.html` 云同步层

### R09 登录按钮不显示 / 按钮无反应 ✅
- **根因**：① 注释中的 `</script>` 被 HTML 解析器当作闭合标签，导致 JS 全体泄露为页面文本；② `build-frontend.sh` 的 sed 全局替换把检查语句 `if(GP_API==='__GP_API_BASE__')` 也替换掉了，导致 `GP_CLOUD` 恒为 false。
- **修复**：提交 `7ac1df7`、`fee26ac`（sed 只替换赋值语句，不全局替换）。
- **证据**：`deploy/build-frontend.sh` 注释明确说明。

### R10 UI 重设计（治愈科技光感） ✅
- **实现**：提交 `dd9cde5` 重写老师大屏；深空渐变 + 霓虹绿点光 + 星球/花园隐喻。
- **证据**：`teacher-dashboard.html` 样式区。

### R11 建班 ✅ / R12 入班码 ✅ / R13 花名册云端同步 ✅
