### R23 登录 500 ✅
- **根因**：Fastify `authenticate` 钩子中 `reply.code(401).send()` **缺少 `return`**，钩子返回后处理器仍继续执行，访问 `req.user.sub` 抛 `TypeError` → 被错误处理器兜成 500 纯文本。
- **修复**：补 `return`（提交 `91feb29`）；同时 `GP.login()` 中 `pullAll()` 加 try/catch，避免「登录成功但同步失败」被误报为登录失败。
- **证据**：`server/src/index.js:29-36`（含注释说明）

### R24 密码眼睛 ✅
- **实现**：密码框右侧 👁️ 按钮，`togglePwd()` 在 `type="password"` / `text` 间切换。

### R25 批量导入失败 500 ✅（本次）
- **现象**：截图提示「导入失败：Internal Server Error」；`gp-api` 日志显示 `POST /students` 返回 **201**，但紧随其后的 `GET /state` 返回 **500**。
- **根因**：`GET /api/classes/:id/state` 的 `boardRows` 查询中 `COALESCE(a.act_points, 0)` 的 `a.act_points` 既不在 `GROUP BY` 也未聚合，Postgres 报 `42803: column "a.act_points" must appear in the GROUP BY clause or be used in an aggregate function`（`events.js:155`）。学生其实已入库，是刷新花名册失败被前端误报成「导入失败」。
- **修复**：① `MAX(a.act_points)` —— 子查询按 `student_id` 分组后每人只有一行，`MAX` 等价取值；② 前端把「新增」与「刷新」的成功判定拆开，刷新超时提示为「已导入 N 位，但花名册刷新超时」。
- **证据**：`server/src/routes/events.js:155`、`teacher-dashboard.html` `importBatch()`

### R26 大屏转圈打不开 ✅
- **根因**：`analytics.mealpick.me/script.js` 的 **TTFB 2.46s** 且脚本带 `defer`，阻塞了 `load` 事件前的关键渲染，页面长时间转圈。
- **修复**：Umami 改为 `window.onload` 之后动态注入（加载失败不影响业务）；`GP.api()` 加 12s `AbortSignal` 超时；初始化时显示「正在加载星球…」的可见提示。
- **证据**：`teacher-dashboard.html` 分析脚本加载段、`GP.api()`、`setLoading()`（第 1392 行）

### R27 访问统计 ✅
- **实现**：Umami 自托管实例，站点 `growth-planet`，website-id `ae23edc6-0fcd-4f4b-8bd6-caf509cb0ef6`；访问 <https://analytics.mealpick.me> 查看。

### R42 删除学生报 400（空 JSON body） ✅

- **现象**：花名册里「删除认领错误的同学」报 `Bad Request`（截图）。
- **根因**：前端 `GP.api()` 对无 body 的 `DELETE` 也强制 `Content-Type: application/json`，Fastify 5 抛 `FST_ERR_CTP_EMPTY_JSON_BODY`（400）。
- **修复**（双层）：① 前端仅在有 body 时设头；② 后端 `server/src/index.js` 注册容忍空 JSON body 的 content type parser（不依赖前端）。
- **验证**：Fastify 最小复现证实 OLD→400、NEW→204；服务端加固测 DELETE 204 / 正常 POST 200 / 非法 JSON 400 / 无 body 200 均正确。
- **证据**：提交 `ac055b2`；详见 [`../../docs/06-测试与验收/故障复盘记录.md#inc-007-删除学生报-bad-request400`](../../docs/06-测试与验收/故障复盘记录.md)（INC-007）。
